# Nini Garments — Kidswear Store Starter

Target age: 0–6 years.

## Included
- Customer storefront
- Categories and product catalogue
- Cart
- Basic demo order creation
- Admin dashboard
- Add product
- Purchase / stock-in
- Automatic stock reduction after demo order
- Sales and basic profit calculation
- Responsive design
- Nini Garments logo

## Important
This version stores data in browser localStorage. It is a working prototype, NOT a production payment/order system.

For the real store we should next connect:
- Cloudflare Pages (frontend)
- Cloudflare Workers (API/backend)
- Cloudflare D1 (database)
- R2 (product images)
- Payment gateway (Razorpay/Cashfree/etc.)
- Secure admin login
- Real order status, invoices and customer data

Do not use the demo admin page for real customer/payment data until authentication and a server database are added.
